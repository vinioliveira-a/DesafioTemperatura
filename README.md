# Desafio de Conversão de Temperatura (°F para °C)

## Descrição do Projeto

Este projeto em Java implementa um programa simples para converter uma temperatura de graus Fahrenheit (°F) para graus Celsius (°C). A conversão é realizada utilizando a fórmula padrão: `(°F - 32) * 5/9 = °C`.

O objetivo é demonstrar o uso de variáveis, constantes e operações aritméticas básicas em Java para resolver um problema prático de cálculo.

## Funcionalidades

O sistema oferece a seguinte funcionalidade:

*   **Conversão de Temperatura**: Converte um valor fixo de temperatura em Fahrenheit (atualmente `126°F`) para Celsius e exibe o resultado no console.

## Tecnologias Utilizadas

*   **Java**: Linguagem de programação principal.

## Estrutura do Código

O código é estruturado em uma classe `DesafioTemperatura` que contém o método `main`. Dentro do método `main`, são definidas constantes para o ajuste (`32`) e o fator de conversão (`5.0/9.0`), uma variável para a temperatura em Fahrenheit (`126`), e o cálculo da temperatura em Celsius é realizado e impresso no console.
